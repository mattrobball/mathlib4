# Blueprint / dependency graph for Bridgeland, *Stability conditions on triangulated categories*

## 0. Scope and audited starting point

This document is a formalization blueprint for Bridgeland's Annals paper, aligned with the current branch layout in
`feat/bridgeland-section4-quasiabelian`.

It is written for an advanced Lean formalization agent. The goals are:

1. make the dependency order explicit,
2. unfold each paper statement until the ingredients are recognizable Mathlib objects,
3. isolate the real blockers in the current repository,
4. atomize proofs so that each lemma is small and context-light.

### 0.1 Paper scope

The paper is logically organized as follows.

```text
§2  Stability functions on abelian categories and HN filtrations
§3  t-structures and slicings
§4  quasi-abelian interval categories P(I)
§5  stability conditions; equivalence with heart + HN stability function
§6  topology on Stab(D)
§7  deformation theorem
§8  metric and group actions on Stab(D)
§9  elliptic curve computation
```

### 0.3 Critical audit findings

These are the main places where the current repo does **not yet match the paper cleanly**.

#### A. The current `QuasiAbelian` class does not match Bridgeland/Schneiders in the needed generality

The file `Slicing.lean` encodes quasi-abelianity using pullbacks of `NormalEpi` and pushouts of `NormalMono`.
Bridgeland's section 4 needs pullbacks of **strict epimorphisms** and pushouts of **strict monomorphisms**.
Those are not the same notions in a general preabelian setting.

**Action item:** refactor section 4 around an explicit `Strict` / `StrictMono` / `StrictEpi` API. Do not build section 7 on the current `QuasiAbelian` class.

#### B. `Slicing.intervalProp` is weaker than the actual categorical object needed later

The paper uses the **full subcategory** `P(I)` generated by phases in `I`, and later uses its exact/quasi-abelian structure, finite length, strict subobjects, strict quotients, and HN filtrations.
The current repo only gives an object predicate.

**Action item:** define an interval full subcategory / object property together with its inherited categorical structure.

#### C. `HNFiltration.phiPlus` / `phiMinus` currently depend on a chosen filtration

In the paper the HN decomposition in a slicing is unique up to isomorphism, hence `φ⁺(E)` and `φ⁻(E)` are intrinsic.
The repo defines them from an arbitrary `HNFiltration` without first proving uniqueness.

**Action item:** prove uniqueness of HN phase data before using `phiPlus`, `phiMinus`, `slicingDist`, or `intervalProp` as intrinsic constructions.

#### D. The current `Slicing` structure does not encode additive-subcategory data

Paper Definition 3.3 uses **full additive subcategories** `P(φ)`.
The current repo uses a predicate `P : ℝ → C → Prop` with closure under iso, shift, hom-vanishing, and HN existence, but not zero/direct-sum closure.

**Action item:** either

- strengthen `Slicing` so that each `P φ` is represented as an `ObjectProperty C` equipped with additive closure data, or
- prove once and for all that the current axioms imply the additive closure actually needed later.

The first option is cleaner.

#### E. Numerical quotient: radical-side choice must be fixed explicitly

The paper writes `N(D) = K(D) / K(D)^⊥` after introducing the Euler form.
The current file chooses the kernel of the **left-curried** map `χ : K₀ C →+ (K₀ C →+ ℤ)`.
That is a valid choice, but the orientation should be made explicit and kept consistent in all subsequent factorization statements.

**Action item:** add a note/lemma fixing the convention, and ensure the same convention is used in Cor. 1.3 and in examples.

#### F. `NumericalStabilityCondition` should store the factored charge as data, not as an existential witness

The current structure stores

```lean
factors : ∃ Z' : NumericalK₀ C χ →+ ℂ, ...
```

This forces repeated use of `choose` and obscures definitional equality.

**Action item:** replace by fields

```lean
factoredZ : NumericalK₀ C χ →+ ℂ
fac      : toStabilityCondition.Z = factoredZ.comp ...
```

#### G. Theorem 9.1 is far beyond the present algebraic-geometry boundary of Mathlib

Section 9 needs coherent sheaves on elliptic curves, `D^b(Coh X)`, Serre duality, numerical Grothendieck group calculations, and autoequivalences/Fourier-Mukai theory.
This should be treated as a separate frontier, not as a continuation of sections 2-7.

## 2. Canonical Lean representations

This section fixes the intended Lean encodings.

### 2.1 Ambient triangulated category

Use the ambient assumptions already adopted by the branch:

```lean
variable (C : Type u) [Category.{v} C] [HasZeroObject C] [HasShift C ℤ]
  [Preadditive C] [∀ n : ℤ, (shiftFunctor C n).Additive] [Pretriangulated C]
```

Upgrade to `[IsTriangulated C]` only when octahedral arguments or localization infrastructure are genuinely needed.

### 2.2 Grothendieck group

Keep the existing file.

Canonical API:

```lean
K₀ C
K₀.of   : C → K₀ C
K₀.of_triangle
IsTriangleAdditive
K₀.lift
```

This is the correct universal-property layer for central charges and Euler pairings.

### 2.3 Heart of a t-structure

The current `TStructure.Basic` has the core relation data but no heart.
The missing object should be a full subcategory.

Suggested definition:

```lean
def TStructure.Heart (t : TStructure C) : Type _ :=
  { X : C // t.le 0 X ∧ t.ge 0 X }
```

Then prove:

```lean
instance : Category t.Heart
instance : Preadditive t.Heart
instance : Abelian t.Heart
```

Short exact sequences in `t.Heart` should be obtained from distinguished triangles whose three vertices lie in the heart.

### 2.4 Boundedness of a t-structure

Paper boundedness is

```text
D = ⋃_{i,j ∈ ℤ} F[i] ∩ F^⊥[j].
```

For the `le`/`ge` encoding, the clean Lean proposition is

```lean
def TStructure.IsBounded (t : TStructure C) : Prop :=
  ∀ E : C, ∃ a b : ℤ, t.ge a E ∧ t.le b E
```

This is the usable form for `Lemma 3.2` and `Proposition 5.3`.

### 2.5 Slicing phases and interval categories

After uniqueness of HN phase data is available, define intrinsic phase bounds:

```lean
def Slicing.phiPlus  (s : Slicing C) (E : C) : ℝ
def Slicing.phiMinus (s : Slicing C) (E : C) : ℝ
```

Then define the interval object property by phase bounds / HN factors:

```lean
def Slicing.IntervalObj (s : Slicing C) (I : Set ℝ) : ObjectProperty C
```

and package the actual full subcategory when categorical structure is needed:

```lean
def Slicing.Interval (s : Slicing C) (I : Set ℝ) :=
  FullSubcategory (s.IntervalObj I)
```

### 2.6 Strict morphisms in quasi-abelian categories

Add a new preabelian API.

Suggested minimal interface:

```lean
class HasImagesAndCoimages (A : Type*) ...

def Strict (f : X ⟶ Y) : Prop := IsIso (coimageToImage f)
def StrictMono (f : X ⟶ Y) : Prop := Mono f ∧ Strict f

def StrictEpi  (f : X ⟶ Y) : Prop := Epi  f ∧ Strict f
```

Then define:

```lean
class QuasiAbelian (A : Type*) ... : Prop :=
  (pullback_strictEpi : ...)
  (pushout_strictMono : ...)
```

This is the version needed for section 4 and section 7.

### 2.7 Local finiteness

Use the paper definition, not the current surrogate.

```lean
class Slicing.IsLocallyFinite (s : Slicing C) : Prop :=
  (exists_eta : ∃ η > 0, ∀ t : ℝ,
      FiniteLengthStrict (s.IntervalCat C (t - η) (t + η)))
```

This is the definition that should drive the code. The `Slicing.IsLocallyFinite`
definition in the branch has now been corrected accordingly. The remaining stale
surrogate is downstream in the legacy helper
`SkewedStabilityFunction.hn_exists_in_thin_interval_of_finiteSubobjects`, which still
assumes `Finite (Subobject _)`. Replacing it merely by ordinary `IsArtinianObject` /
`IsNoetherianObject` on all subobjects would still be too strong. The formal target
has to talk about ACC/DCC on **strict** subobjects / strict quotients in the thin
quasi-abelian category itself. In particular, both:

- the abelian HN existence theorem of Section 2, and
- the thin quasi-abelian first-SES / HN recursion of Section 7,

have to be driven by the paper's chain conditions / finite-length argument, not by
enumerating subobject sets.

## 3. Section-by-section blueprint

## 3A. Section 2: stability functions and HN filtrations on abelian categories

### 3A.1 Definitions

#### Node 2.1 — stability function on an abelian category

Paper content: Definition 2.1.

Lean target:

```lean
structure StabilityFunction (A : Type*) [Category A] [Abelian A] where
  Z        : K₀ A →+ ℂ
  upper    : ∀ E : A, ¬ IsZero E → Z (K₀.of A E) ∈ upperHalfPlane
```

with

```lean
upperHalfPlane : Set ℂ := { z | 0 < Complex.im z ∨ (Complex.im z = 0 ∧ 0 > Complex.re z) }
```

or an equivalent ray-based definition.

#### Node 2.2 — phase function

```lean
def StabilityFunction.phase (Z : StabilityFunction A) (E : A) (hE : ¬ IsZero E) : ℝ
```

Range lemma:

```lean
theorem phase_mem_Ioc : phase Z E hE ∈ Set.Ioc 0 1
```

#### Node 2.3 — semistability

```lean
def StabilityFunction.IsSemistable (Z : StabilityFunction A) (E : A) : Prop :=
  ¬ IsZero E ∧ ∀ A' : Subobject E, A' ≠ ⊥ →
    phase Z A'.obj ?_ ≤ phase Z E ?_
```

Also prove the quotient version.

#### Node 2.4 — HN filtration in an abelian category

Represent HN filtration as a finite increasing chain of subobjects with semistable quotients of strictly decreasing phase.
A good implementation uses either:

- a chain `Fin (n+1) → Subobject E`, or
- a finite list of quotient data with exactness witnesses.

Recommended: use subobject chains in the abelian section, and convert to `PostnikovTower` only when entering the triangulated section.

### 3A.2 Small lemmas that should be proved before Proposition 2.4

#### Node 2.L1 — quotient reformulation of semistability

If `E` is nonzero, then

```text
E semistable  ↔  every nonzero quotient E ↠ B has φ(E) ≤ φ(B).
```

Mathlib pieces: `Subobject`, quotient object, exactness in abelian categories.

#### Node 2.L2 — phase monotonicity for nonzero maps between semistables

If `f : E ⟶ F` is nonzero and `E`, `F` are semistable, then `φ(E) ≤ φ(F)`.

Proof atoms:

1. form `im f ≅ coim f`,
2. `im f` is both a quotient of `E` and a subobject of `F`,
3. use the two semistability inequalities.

This lemma is the key uniqueness input.

#### Node 2.L3 — uniqueness of HN filtrations

Use the standard comparison of top phases via nonzero maps from the first semistable factor.
This can be proved after Node 2.L2.

### 3A.3 Proposition 2.4 blueprint

#### Node 2.4a — existence of a semistable subobject of phase at least `φ(E)`

Lean target:

```lean
theorem exists_semistable_subobject_ge_phase
  (hchain : no infinite phase-increasing strict subobject chains)
  {E : A} (hE : ¬ IsZero E) :
  ∃ A' : Subobject E, A' ≠ ⊥ ∧ IsSemistable Z A'.obj ∧ phase Z A'.obj _ ≥ phase Z E hE
```

Proof atoms:

1. if `E` semistable, take `E`,
2. else choose a destabilizing subobject with larger phase,
3. iterate,
4. terminate by the first chain condition.

#### Node 2.4b — existence of a semistable quotient of phase at most `φ(E)`

Dual to 2.4a using the second chain condition.

#### Node 2.4c — maximally destabilizing quotient (mdq)

Package:

```lean
structure IsMDQ (q : E ⟶ B) : Prop :=
  (epi        : Epi q)
  (nonzero    : ¬ IsZero B)
  (semistable : IsSemistable Z B)
  (minimal    : ∀ q' : E ⟶ B', ...)
```

The exact shape can be adapted, but the mdq property should be a separate reusable definition.
Status update:
this package now exists privately in `StabilityFunction.lean`, and the required
arbitrary-quotient comparison / factor-through transport have also been formalized
(`IsMDQ.phase_le_of_quotient`, `IsMDQ.of_epi_factor`), so Node 2.4c is no longer a
live blocker.

#### Node 2.4d — mdq existence

Proof atoms:

1. if `E` semistable, `𝟙 E` is an mdq,
2. else choose `0 → A → E → E' → 0` with `A` semistable and `φ(A) > φ(E) > φ(E')`,
3. if `E' ↠ B` is mdq, then `E ↠ B` is mdq,
4. iterate along descending quotient chain,
5. terminate by the second chain condition.

#### Node 2.4e — HN filtration construction by induction on mdq kernels

Proof atoms:

1. if `E` semistable, done,
2. choose mdq `E ↠ B`,
3. kernel `E'` has strictly larger phase than `E`,
4. recursively build HN for `E'`,
5. append `B` as final factor,
6. prove strict phase decrease from mdq minimality.

Status update:
this node is now formalized faithfully via a local induction on nonzero subobjects of
an ambient object and a compiled append step for the final mdq quotient.

#### Node 2.4f — final theorem

```lean
theorem hasHN_of_chain_conditions : HasHNProperty Z
```

Status update:
the corrected finite-length theorem is now compiled as
`StabilityFunction.hasHN_of_artinian_noetherian`.

This is the exact section-2 endpoint needed later inside hearts and thin quasi-abelian categories.

## 3B. Section 3: t-structures and slicings

### 3B.1 Definition 3.1: t-structures

The repo already has `TStructure C`; use it.

What is missing is a bridge theorem between Bridgeland's single-subcategory presentation and Mathlib's `le/ge` presentation.

#### Node 3.1a — equivalence of presentations

Show that a paper-style full subcategory `F` satisfying

- `F[1] ⊂ F`,
- every `E` fits into `F → E → G` with `G ∈ F⊥`,

is equivalent to a `TStructure C`.

This is optional if the whole development is rewritten directly in the existing `TStructure` language.
The more practical option is: **do not formalize paper Definition 3.1 literally; work directly with `TStructure C`.**

### 3B.2 Lemma 3.2: characterization of hearts of bounded t-structures

This is the first major missing bridge result.

#### Node 3.2a — `heart -> conditions (a),(b)`

Dependencies:

- `TStructure.Heart`,
- boundedness,
- heart shift orthogonality,
- truncation triangles.

Proof atoms for (a):

1. reduce to vanishing `Hom(A, B[k])` for positive `k`,
2. use `zero'` axiom of the t-structure after shifting.

Proof atoms for (b):

1. use boundedness to choose an interval of degrees containing `E`,
2. iterate truncation triangles,
3. identify each cohomology piece as an object of the heart shifted by an integer.

#### Node 3.2b — `conditions (a),(b) -> bounded t-structure`

This is harder and should be split.

Define:

```lean
F := extensionClosure of { A[k] | A ∈ heartCandidate, k ≥ 0 }
```

Need small lemmas:

- `F[1] ⊂ F`,
- `F⊥[1]` is the extension closure of negative shifts,
- every `E` admits a triangle with vertices in these two classes using the decomposition from (b),
- the candidate heart is exactly `F ∩ F⊥[1]`.

This requires a good extension-closure API. Reuse `Triangulated.Subcategory` if possible.

### 3B.3 Definition 3.3: slicing

Recommended final structure:

```lean
structure Slicing where
  P              : ℝ → ObjectProperty C
  iso_closed     : ...
  additive       : ...            -- or encoded via full additive subcategories
  shift_iff      : ...            -- `P (φ+1)` iff shift of `P φ`
  hom_vanishing  : ...
  hn_exists      : ∀ E, ¬ IsZero E → Nonempty (HNFiltration ... E)
```

The current structure is close but should be strengthened as in audit note D.

### 3B.4 HN decompositions in slicings

#### Node 3.3a — uniqueness of phase list / semistable factors

Before defining intrinsic `phiPlus`, `phiMinus`, prove uniqueness up to isomorphism of the phase sequence and semistable factors in Definition 3.3(c).

Proof strategy:

- compare the top phase on two filtrations using a nonzero map from a top semistable factor,
- peel off the first factor,
- induct on filtration length.

#### Node 3.3b — intrinsic phase bounds

Once 3.3a is available, define intrinsic

```lean
phiPlus  : C → ℝ
phiMinus : C → ℝ
```

and prove:

```lean
phiMinus E ≤ phiPlus E
phiMinus E = phiPlus E ↔ ∃ φ, s.P φ E
```

### 3B.5 Interval subcategories `P(I)`

#### Node 3.3c — extension-closed characterization

For any interval `I`, define the extension-closed full subcategory `P(I)` generated by the phase slices `P(φ)` for `φ ∈ I`.

Then prove the equivalence:

```text
E ∈ P(I)  ↔  E = 0 or every HN factor of E has phase in I.
```

This is the correct bridge between the categorical and phase-bound presentations.

### 3B.6 Lemma 3.4

#### Node 3.4 — triangle phase-bound inequalities inside an interval of width ≤ 1

Lean target:

```lean
theorem phiPlus_left_le_phiPlus_mid
  (hI : interval_length I ≤ 1)
  (hT : Triangle.mk f g h ∈ distTriang C)
  (hA : A ∈ P(I)) (hE : E ∈ P(I)) (hB : B ∈ P(I)) :
  phiPlus A ≤ phiPlus E
```

and its dual for `phiMinus`.

Proof atoms follow the paper exactly:

1. reduce to the left inequality,
2. normalize the interval to `[t, t+1]`,
3. choose a nonzero top-phase semistable factor `A⁺ → A`,
4. if `φ(A⁺) > φ⁺(E)`, then `A⁺ → E` vanishes,
5. factor through `B[-1]`,
6. use `B[-1] ∈ P(≤ t)` to contradict `φ(A⁺) > t`.

### 3B.7 t-structures induced by a slicing

This is used repeatedly and should be formalized as infrastructure.

#### Node 3.5a — `P(> φ)` and `P(≥ φ)` define t-structures

Construct `TStructure`s from a slicing.

#### Node 3.5b — their hearts

Prove:

```text
heart(P(> φ))  = P((φ, φ+1])
heart(P(≥ φ))  = P([φ, φ+1))
```

This is the exact bridge used in sections 4 and 5.

## 3D. Section 5: stability conditions

### 3D.1 Definition 5.1

The current repo structure is acceptable after the slicing refactor.

Recommended final form:

```lean
structure StabilityCondition where
  slicing      : Slicing C
  Z            : K₀ C →+ ℂ
  compat       : ∀ {φ E}, slicing.P φ E → ¬ IsZero E →
                   ∃ m : ℝ, 0 < m ∧ Z (K₀.of C E) = m * exp (π * φ * I)
  locallyFinite : slicing.IsLocallyFinite
```

### 3D.2 Lemma 5.2: each `P(φ)` is abelian

#### Node 5.2a — embed `P(φ)` in the heart `A = P((φ-1, φ])`

Need 3.5b.

#### Node 5.2b — kernels and cokernels remain in `P(φ)`

For a morphism `f : E ⟶ F` in `P(φ)`, take its kernel and cokernel in the heart.
Use Lemma 3.4 on the associated short exact sequences / triangles to show they still lie in `P(φ)`.

### 3D.3 Proposition 5.3: equivalence with a bounded heart + HN stability function

This theorem should be formalized as two constructions plus inverse lemmas.

#### Node 5.3a — from `σ` to heart data

Input: `σ : StabilityCondition C`.

Output:

```lean
structure HeartData where
  t          : TStructure C
  bounded    : t.IsBounded
  heart      := t.Heart
  Zheart     : K₀ heart →+ ℂ
  isStabFn   : StabilityFunction heart
  hasHN      : HasHNProperty isStabFn
```

Proof atoms:

1. `t := slicing.toTStructure_gt 0`,
2. heart is `P((0,1])`,
3. identify `K₀ heart ≃ K₀ C`,
4. restrict `Z`,
5. semistables in the heart are exactly the objects of `P(φ)` for `0 < φ ≤ 1`,
6. the slicing decomposition of an object of the heart is an HN filtration.

#### Node 5.3b — from bounded heart data to a stability condition

Input: bounded t-structure `t` + stability function on `t.Heart` with HN property.

Construction:

1. define `P(φ)` for `0 < φ ≤ 1` as the semistable objects of `t.Heart` of phase `φ`,
2. extend by shifts using `P(φ+n) := P(φ)[n]`,
3. prove hom-vanishing using heart orthogonality and phase monotonicity for semistables,
4. decompose any `E : C` using bounded t-structure pieces and HN filtrations in the heart,
5. prove compatibility with `Z`.

#### Node 5.3c — inverse lemmas / extensionality

Need two inverse statements up to definitional transport of the heart equivalence.

### 3D.4 Definition 5.7: local finiteness

Paper reference:

- The proof direction matters:
  start with a destabilizing strict short exact sequence in the larger thin category `C`,

  exact sequence to `B`.
- Negative guidance:

  common-heart bookkeeping argument that skips the paper's quotient decomposition.
